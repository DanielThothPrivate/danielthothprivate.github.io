# Privacy policy - Marvin Haus

Marvin Haus is a private, non-commercial home assistant used by one household.

**What it accesses:** the household's own Google Calendar, only to show and create appointments on the household's Home Assistant server at home.

**Where data goes:** calendar data is stored only on that home server. It is not sold, shared with third parties or used for advertising.

**Deleting access:** access can be removed at any time at https://myaccount.google.com/permissions.
